# Changelog

Every version of Performance Booster and what it brought. Turkish: [CHANGELOG.tr.md](CHANGELOG.tr.md).

## 1.0.0 - 2026-11-01

### New
- Live: CPU, RAM, graphics card, disk and network with 60-second charts; ping, jitter and loss to the router and to the DNS server in use; an issues panel with fixes. Click a card to see the apps that use that resource most, including per-app network traffic.
- Processes: every running app with CPU, RAM, disk, graphics card and connections; sort, search, end task, change the priority, add it to the game list, keep it at full speed while a game runs or open its file location.
- Updates: app updates through winget and driver updates through Windows Update; pin an app, skip a version, see the details, cancel one update or all of them. Running apps are closed only with your permission.
- Programs: desktop programs and Store apps with size, install date and last use; silent uninstall, a scan for leftovers (files go to the Recycle Bin, registry keys are backed up first) and removal of broken entries.
- Settings: power, graphics, scheduling, memory, input, network and network adapter settings, NVIDIA driver options, MSI mode, device power saving, unused devices and rarely needed services; each with its current and recommended value, impact and undo, and a search box.
- Game mode: while a game runs (one from your list, or one Windows recognizes), a power plan for games, other apps on low priority, efficiency mode and the cores the game does not need, the standby list emptied when memory runs low, Wi-Fi network search paused, and the high-performance graphics card on computers with two. After each game, the Last game card shows what held it back. Games can be excluded from Defender's real-time scanning; a finer Windows timer is held while the app runs.
- Latency: driver latency (DPC and ISR times per driver and processor core), a mouse polling test and the interrupts of the devices that matter in games.
- Network: speed test with latency under load (bufferbloat grade) and a DNS speed test, the normal way and encrypted (DNS over HTTPS), that spots DNS redirection; one click switches to a faster DNS server.
- Startup and System tabs with hardware details and hints, cleanup tools and a text report.
- The app updates itself and shows what is new after an update. English and Turkish.
